### Отложено сознательно — `peak_field` как третья метрика

Сейчас программа считает затухание по **энергии импульса** (`∫E²dt`). Для нелинейных
экспериментов существеннее **пиковая напряжённость поля** `max|E(t)|` — именно она задаёт
режим взаимодействия с образцом.

Пока аттенюатор не искажает форму импульса, обе величины связаны жёстко (`E_peak ∝ √U`),
и отдельная метрика не нужна. Расходятся они там, где форма плывёт: у краёв рабочей
полосы, в жёлтой зоне, при заметной дисперсии. Это ровно эффект, показанный на Fig. 4
у Kaltenecker 2019.

**Реализация, когда понадобится:** обратное преобразование Фурье спектра после
аттенюатора → `peak_field_ratio` в ответе `/forward`, плюс приёмочная проверка
«при плоском `T(ν)` метрики совпадают в пределах 0.01 дБ».

**Критерий запуска работы:** появление пользователя, которому нужна напряжённость на
образце, а не мощность. Для спектроскопических применений метрика избыточна и только
усложняет интерфейс.

Ключевой дифференциатор, который надо удерживать во всех сравнениях:

приборе, в этой полосе, с этим ротатором» с разбором причин.** Это и есть продукт.

## 4. Задания владельцу — что найти или предоставить

### 4.1. Данные и характеристики прибора (блокирующее)

1. **Шаг, люфт, повторяемость, диапазон ротаторов** — без этих трёх чисел проверка F4
   не работает, а без неё приложение будет уверенно врать на глубоких затуханиях.
2. **Тип детектора** (когерентный / мощностной) для каждой рабочей установки.
3. **Каталожные `P` и `D`** серийных аттенюаторов Tydex + серийники, под которые делаем паспорта.
4. **Полоса и типовой источник** — для дефолтного `w(ν)`.
5. Микрофото 356att **со своей калибровочной граткулой** — до сих пор блокирует
   четвёртую точку закона `D_eff` (перенос калибровки PureWave не сработал: `P_fft` вышел
   66.6 / 94.3 / 40.2 мкм при номинале 16).
6. Геометрия `series1–5` (паспорт или микрофото) — блокирует полный M5-фит по ним.

### 4.2. Литература — что нужно достать

Приоритет по убыванию:

1. **Costley et al. 1977**, `10.1364/JOSA.67.000979` — PDF уже лежит в `litrev/pdfs/`, но
   **не проиндексирован**: нет строки в `research/literature/INDEX.md` и нет извлечённого текста
   в `research/literature/txt/`. Это единственная неучтённая статья из двадцати. Нужно
   `pdftotext` + строка в индексе.
2. **Marcuvitz, Waveguide Handbook (1951)**, разделы по индуктивным/ёмкостным решёткам —
   первоисточник эквивалентных схем. Есть в открытом доступе (IET reprint / archive.org).
3. **Свежее (2020+) по THz-аттенюаторам и деградации поляризации на широкой полосе** —
   поиск по цитированиям Kaltenecker 2019 вперёд:
   `python THz-WGP-Analysis/litrev/metasearch.py search "terahertz attenuation wire grid broadband polarization" --limit 25 --oa-only`
4. **Метрология затухания**: как в оптике/СВЧ принято аттестовывать переменный аттенюатор
   (неопределённость, прослеживаемость, поверка). Ключевые слова: *variable attenuator
   calibration uncertainty*, *step attenuator metrology*, NIST/PTB technical notes.
   Нужно, чтобы паспорт прибора был не самодельным форматом, а соответствовал практике.
5. **Разброс `D_eff` и намотка**: работы по влиянию беспорядка намотки на диффузное
   (некогерентное) рассеяние в решётках — это единственная живая гипотеза о происхождении
   показателя `γ` (когерентное рассеяние отвергнуто в HN4: `kσ ≈ 0.05`).
   Ключевые слова: *random positioning errors wire grid*, *diffuse scattering wire array THz*.
6. **Тонкоплёночные аттенюаторы Cr на HR-Si** (Kaltenecker §5 + его ссылка [47]) — если
   планируется схема S7-v2.

### 4.3. Продукты — что посмотреть глазами

- Страницы Thorlabs / Newport по переменным аттенюаторам: как формулируют границы
  применимости и что кладут в спецификацию.
- Собственный Attenuator Studio: прогнать реальный кейс «−40 дБ» и зафиксировать, что
