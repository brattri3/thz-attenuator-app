# 01 — Физическая модель, экстраполяция и бюджет неопределённости

Центральный вопрос документа: **как честно считать затухание на частотах, на которых
параметры прибора не подгонялись.**

---

## 1. Прямая модель

### 1.1. Один WGP

Матрица Джонса решётки, ось пропускания которой (⊥ проводам) ориентирована под углом `φ`:

```
J(φ, ν) = R(φ) · diag(t⊥(ν), t∥(ν)) · R(−φ),      R(φ) = [[cos φ, −sin φ], [sin φ, cos φ]]
```

**Конвенция углов, зафиксированная в `research/two_wgp/model_2wgp.py`:** угол — это
ориентация **оси ПРОПУСКАНИЯ**; провода лежат под `угол + 90°`. Отступление от неё —
источник ошибки знака на 90°, это была ошибка №1 всех Фаз 1–3.

`t⊥`, `t∥` — комплексные амплитудные коэффициенты Бланко (эквивалентные схемы,
`unified_optimizer/model_blanco.py:102,118`; векторизованно — `research/experiments/model_core.py:blanco_t`),
функции трёх величин: `P/λ`, `D_eff/P`, и поверхностного импеданса металла (Друде).

### 1.2. Цепочка прибора

```
E_out(θ₁, θ₂, ν) = d† · J₂(θ₂, ν) · J₁(θ₁, ν) · E_in(ψ)
```

- `E_in(ψ)` — линейная поляризация источника под углом `ψ`;
- `d` — ось чувствительности детектора;
- `d†·(…)` — **комплексная проекция**: THz-TDS меряет поле, а не мощность.

Реализовано: `research/two_wgp/model_2wgp.py:forward_field()`. Мощностное затухание —
`attenuation() = |E_out|²`.

### 1.3. Идеальный предел — то, к чему всё сводится

При `t⊥ = 1, t∥ = 0`, `E_in ∥` оси WGP1, `d ∥` оси WGP2:

```
E_out = E_in cos²(θ₁ − θ₂)        →        U_out = U_in cos⁴(θ₁ − θ₂)
```

Это Eq. 3 и Fig. 5 Kaltenecker 2019. **`cos⁴`, не `cos²`** — потому что элементов два.
Приложение обязано показывать эту кривую как опорную «идеальную», от неё считается
отклонение реального прибора.

Для реальных `t⊥, t∥` (x-поляризованный вход, WGP2 по оси x):

```
E_out = ( t⊥·(t⊥cos²θ + t∥sin²θ) ,  t∥·(t⊥ − t∥)·sinθ·cosθ )
```

Два следствия для UI:
- **вносимые потери** при θ=0: `|t⊥|⁴` по мощности (≈ 88 % @1 ТГц для типовой решётки —
  ровно то число, что фигурирует в Attenuator Studio);
- **кросс-поляризованная компонента максимальна на 45°**, а не в тени. При широкой полосе
  и комплексных `t` это даёт **эллиптичность и поворот** выходной поляризации — главное
  предупреждение статьи Kaltenecker.

### 1.4. Поправки поверх ядра (форма M5)

```
t∥  →  ( t∥ + η₀·ν^a · e^{ j(δ₀ + 2π ν τ_leak) } ) · e^{ −j2π ν τ_par }
t⊥, t∥  →  ×  exp( −½ · (L/4.343) · ν^γ )          рассеяние, per-element
всё      →  ×  exp( −j2π ν τ )                      общая групповая задержка
```

- `η₀, a, δ₀, τ_leak` — утечка параллельного канала (HN2/HN8; подтверждена независимо
  энергией Парсеваля HN7). `τ_leak ≈ 0.19 пс`, `η ≈ 0.012…0.036`.
- `L, γ` — феноменологическое рассеяние. **`γ` не идентифицируется** (вырождено с утечкой,
  0.2…4.2 по конфигурациям) — см. §4.
- `θ_offset` — установочный перекос ротатора относительно оси решётки.

## 2. Две метрики затухания

### 2.1. Спектральное затухание

```
A(θ₁, θ₂, ν) [дБ] = −10 · log₁₀ ( |E_out(θ₁,θ₂,ν)|² / |E_ref(ν)|² )
```

Выбор `E_ref` задаёт **режим отсчёта** (см. `02_SCENARIOS.md` §2):
абсолютный (`E_ref` = вход) или относительный (`E_ref` = поле при опорных углах).

### 2.2. Интегральное (широкополосное) затухание

По Парсевалю, энергия импульса `U = ∫E²(t)dt = ∫|E(ν)|²dν`:

```
A_int(θ₁,θ₂) [дБ] = −10 · log₁₀ (  ∫ w(ν)·|E_out(θ₁,θ₂,ν)|² dν  /  ∫ w(ν)·|E_ref(ν)|² dν  )
```

**`w(ν)` — спектральный вес источника, и он обязателен.** Без него «интегральное затухание»
не определено: одно и то же положение углов даёт разное интегральное затухание для узкой
и широкой полосы (это буквально Fig. 5 в статье — три разных импульса, три разные кривые).

Источники `w(ν)`, которые приложение обязано поддерживать:
1. **измеренный фон** — загруженный `*_bg.txt` (предпочтительно; так делает весь этот репозиторий);
2. **пресеты источников** — LiNbO₃ (≤2 ТГц), органический кристалл (≤5 ТГц), воздушная плазма
   (≤20 ТГц), PCA-эмиттер (≤3 ТГц); ровно те три класса, что разбирает Kaltenecker;
3. **прямоугольное окно** `[f₁, f₂]` — самый честный вариант, когда спектр неизвестен;
4. **аналитическая гауссова полоса** `(ν₀, Δν)` — для быстрой прикидки.

> **Правило UI**: интегральное число никогда не показывается без подписи, по какому весу
> оно посчитано. Смена `w(ν)` меняет результат на единицы дБ.

### 2.3. Мощностной детектор vs когерентный

| Детектор | Что меряет | Формула |
|---|---|---|
| Когерентный (PCA, ЭО-стробирование) | проекцию **поля** на ось `d` | `A = −20 log₁₀ |d†E_out| / |d†E_ref|` |
| Мощностной (боло, пироприёмник, ячейка Голея) | полную **мощность** | `A = −10 log₁₀ (‖E_out‖² / ‖E_ref‖²)` |

Мощностной приёмник видит **и** кросс-поляризованную компоненту, которой когерентный
детектор с осью `d` не видит вовсе. Величина расхождения определяется тем, есть ли за
вращаемым элементом анализатор, и **максимальна не в тени, а на 45°** — там, где
кросс-компонента `t∥(t⊥−t∥)·sinθ·cosθ` достигает максимума (на 90° она тождественно нулевая).

| Схема | Где максимум расхождения | Величина | Почему |
|---|---|---|---|
| **Одиночный WGP** перед приёмником | θ = 45° | **3.0 дБ** | поляризация повёрнута на 45°, мощностной приёмник видит вдвое больше энергии, чем когерентный по оси `d` |
| **Пара WGP** (S1) или сэндвич (S3) | θ ≈ 80° | **≈ 0.02 дБ** | второй элемент вычищает повёрнутую компоненту; остаток подавлен как `1/ER` |

Числа посчитаны для реального прибора (`t⊥ ≈ 1`, `t∥ ≈ 0.02`) и подтверждены численно —
приёмочная проверка №5 в `attenuator_app/selftest.py` даёт **3.04 дБ** для схемы S0.

Практический вывод: **в штатной схеме прибора с анализатором выбор типа детектора почти
ничего не меняет**; он становится критичным только там, где за вращаемым элементом
анализатора нет, а также в схеме S2 при `θ₂ ≠ d`. Тип детектора всё равно остаётся
обязательным полем паспорта установки — но не потому, что от него зависят единицы, а
потому, что он задаёт, какая величина стоит в числителе.

Это разделение — не изобретение проекта: официальный паспорт продукта
(`ATT-11-16-CA85`, `THz-Spectroscopy-Python-Manual2/text/passport.tex`, разд. 4)
описывает ровно два сценария, и они алгебраически совпадают с формулами таблицы выше:

- **Scenario A** (PCA Menlo Tera K8, поляризационно-чувствительный) =
  `detector: coherent`:  `T = |t⊥cos²(θ−θ_off) + t∥sin²(θ−θ_off)|² + T_noise`
- **Scenario B** (болометр / ячейка Голея, нечувствительный) =
  `detector: power`:  `T = |t⊥|²cos²(θ−θ_off) + |t∥|²sin²(θ−θ_off) + T_noise`

Совпадение проверяется в одну строку: `|E_x|² + |E_y|²` для одиночной решётки
сворачивается точно в `|t⊥|²cos²θ + |t∥|²sin²θ` (перекрёстные члены сокращаются).

## 3. Экстраполяция за пределы полосы калибровки — ядро задачи

### 3.1. Почему это вообще возможно

Потому что модель **параметрическая и физическая**, а не подгоночная кривая. Сплайн или
полином по `T(ν)` за полосой бессмысленны. Бланко + Друде — это решение уравнений
электродинамики решётки; параметры (`P`, `D_eff`, проводимость) частоты не содержат, вся
частотная зависимость выводится. Поэтому вне полосы модель **имеет право** считать —
в пределах области своей физической применимости.

**Проектное решение: разделить модель на два слоя с разным правом на экстраполяцию.**

| Слой | Состав | Экстраполяция |
|---|---|---|
| **Ядро (physical core)** | Бланко `t⊥,t∥` + Друде | **разрешена** на всей области применимости §3.2 |
| **Феноменология (dressing)** | рассеяние `L·ν^γ`, утечка `η₀·ν^a`, `τ_leak`, `τ_par` | **степенные законы, подогнанные в узкой полосе** — за полосой экстраполируются только с демпфированием и растущей неопределённостью (§3.4) |

Приложение всегда считает **обе** величины и показывает их вместе:
`T_core(ν)` и `T_full(ν)`. Расхождение между ними за полосой — бесплатный и честный
индикатор «насколько мы додумываем».

### 3.2. Область физической применимости — три зоны

Определяются геометрией решётки, а не данными:

```
ν_анomaly = c / P          первый дифракционный порядок (аномалия Вуда, λ = P)
```

Для `P = 15.5 мкм` → **19.3 ТГц**; для `P = 24.9 мкм` → 12.0 ТГц; для `P = 38.8 мкм` → 7.7 ТГц.

| Зона | Диапазон | Статус | Поведение приложения |
|---|---|---|---|
| 🟢 **Надёжная** | `ν ≤ ν_anom / 6` | `t⊥→1`, `t∥→0`, поляризация сохраняется | считать, показывать без предупреждений |
| 🟡 **Деградация** | `ν_anom/6 < ν < ν_anom/1.5` | растёт `t∥`, поляризация вращается и эллиптизируется | считать, **обязательный баннер** «нарушение чистоты поляризации», показ эллиптичности |
| 🔴 **Запрет** | `ν ≥ ν_anom / 1.5` | решётка работает как дифракционная, а не как поляризатор | **не показывать число**, показывать причину |

Практический ориентир Kaltenecker: лучшие свободновисящие решётки пригодны как аттенюатор
**примерно до 4 ТГц**; выше — «significant and frequency-dependent modifications of the
polarization state». Для `p = 12.5 мкм` аномалия на 24 ТГц, а практический предел — 4 ТГц,
то есть ≈ `ν_anom/6`. Отсюда и взят коэффициент границы зелёной зоны.

Снизу область не ограничена физикой: при `ν → 0` модель асимптотически точна
(`t⊥ → 1`, `t∥ → 0`). **Экстраполяция вниз безопасна**, и это надо явно сказать в UI —
пользователи по умолчанию боятся любой экстраполяции одинаково.

### 3.3. Демпфирование феноменологических степенных законов

`exp(−½·(L/4.343)·ν^γ)` при `γ ≈ 2` и экстраполяции с 1.5 до 6 ТГц даёт множитель в
`16×` в показателе — то есть модель уедет в ноль на физически неоправданном основании.
Поэтому за верхней границей полосы калибровки `f_hi`:

```
ν_eff = f_hi + (ν − f_hi) / (1 + (ν − f_hi)/Δ_soft)          # soft-clip, Δ_soft = f_hi по умолчанию
```

то есть аргумент степенного закона насыщается вместо неограниченного роста. Это **не
физика, а инженерный предохранитель**; он обязан быть явно отмечен в выдаче флагом
`dressing_clipped: true` и настраиваться (`off | soft | freeze`), где `freeze` замораживает
феноменологические поправки на их значении в `f_hi`.

Ниже нижней границы `f_lo` феноменология **замораживается** всегда: утечка и рассеяние
подгонялись там, где есть сигнал; продлевать степенной закон в область, где `ν^γ → 0`,
физически безобидно, но `η₀·ν^a → 0` даёт ложное «идеальный поляризатор на низких частотах».
Ставим `η(ν < f_lo) = η(f_lo)`.

### 3.4. Бюджет неопределённости

Итоговая дисперсия амплитуды пропускания на частоте `ν`:

```
σ²_T(ν)  =  J(ν) · Σ · J(ν)ᵀ                     (A) распространение ковариации параметров
          +  [ κ · |T_full(ν) − T_core(ν)| ]²     (B) неопределённость формы модели
          +  σ²_deg(ν)                            (C) штраф зоны деградации
```

- **(A)** `Σ` — ковариационная матрица из фита; её уже отдаёт
  `research/experiments/t20_weighted_fit.py` (ковариационные ошибки + опционально bootstrap
  по повторам). `J` — численный якобиан модели по параметрам. Внутри полосы это
  доминирующий и достаточный член.
- **(B)** расхождение «ядро vs полная модель», взвешенное `κ` (дефолт `κ = 1`, то есть
  расхождение считается за одну сигму). **За полосой (B) становится главным** и растёт
  естественным образом — ровно то поведение, которое нужно.
- **(C)** `σ_deg = 0` в зелёной зоне; в жёлтой линейно растёт до величины `|t∥/t⊥|`
  на границе красной. Отражает то, что в зоне деградации сама постановка «скалярное
  затухание» перестаёт быть корректной.

Дополнительно — **отдельная развёртка по `γ`**: поскольку `γ` не идентифицируется
(0.2…4.2 по конфигурациям, Фаза 3 / HN11), приложение считает огибающую по диапазону `γ`
из паспорта и показывает её за полосой как заштрихованный коридор. Это самая честная
визуализация того, что мы про рассеяние на самом деле не знаем.

### 3.5. Что приложение отдаёт наружу по каждой точке

```json
{ "freq_thz": 3.2, "att_db": 21.4, "sigma_db": 2.9,
  "zone": "amber", "extrapolated": true, "dressing_clipped": true,
  "core_only_db": 19.8, "gamma_envelope_db": [18.1, 24.6] }
```

Никогда — голое число без `zone` и `sigma_db`. Это главное функциональное требование
всего документа.

## 4. Что НЕ надо делать (уроки, оплаченные Фазами 1–3)

| Соблазн | Почему нельзя |
|---|---|
| Подставить в модель **номинальный** диаметр проволоки из каталога | Пин к физическому `D` катастрофичен: `dAIC +6000…+9000`, переоценка тени на 7–10 дБ. Только `D_eff` из паспорта. |
| Показать `D_eff`, `η₀`, `γ` как независимо измеренные величины | Они вырождены (корр. ±1.0). Свободный фит даёт `D = 1.85 ± 8.37`. Паспорт хранит **набор параметров как целое**, а не значения по отдельности. |
| Свободно подбирать угловые параметры (`θ_offset`, `φ₂`) холодным стартом | Задача мультимодальна: холодный старт дал `φ₂ = 7.72° ± 0.47` («16σ»), честный мультистарт — `1.58° ± 4.83` (незначим). **Обязателен мультистарт.** |
| Считать «скрещённое положение» = 90° | Измеренный минимум `U(θ)` у Specac — на **~84°**. Калибровать по минимуму. |
| Считать пропускание в тени нулевым | Утечка `η ≈ 0.012…0.036` универсальна на 6 образцах. У прибора есть **пол затухания**. |
| Экстраполировать `ν^γ` вверх без ограничителя | См. §3.3. |
| Аппроксимировать `T(ν)` сплайном/полиномом и продлевать | Не экстраполируется в принципе; вся идея §3.1 в том, что экстраполирует **физика**, а не кривая. |
