# 03 — Оптические схемы, в которых участвует прибор

Приложение не считает «аттенюатор вообще» — оно считает **аттенюатор в схеме**. Схема
определяет, что такое референс, что видит детектор и какие степени свободы есть у решателя.

Обозначения: `E_in(ψ)` — линейная поляризация источника; `WGP(θ)` — решётка с осью
пропускания под углом `θ`; `POL(φ)` — идеальный поляризатор/анализатор; `d` — ось
чувствительности детектора; `⟂` — образец.

---

## 1. Сводная таблица

| ID | Схема | Подвижно | Выходная поляризация | Что считаем | Статус |
|---|---|---|---|---|---|
| **S1** | `E_in → WGP(θ) → WGP(φ₂ фикс) → d` | θ | фиксирована по `φ₂` | штатный аттенюатор | **база, MVP** |
| **S2** | `E_in → WGP(θ₁) → WGP(θ₂) → d` | θ₁, θ₂ | управляемая | затухание + азимут | MVP |
| **S3** | `POL(0) → WGP(θ) → POL(0) → d` | θ | жёстко фиксирована | «сэндвич», эталон `cos⁴` | MVP |
| **S4** | `… аттенюатор → ⟂ образец → анализатор → d` | θ | | спектроскопия с ослаблением | v1 |
| **S5** | `… образец → аттенюатор → d` | θ | | защита детектора | v1 |
| **S6** | аттенюатор как калиброванный «leaky» элемент поляриметра | θ | | in-situ калибровка | v2 |
| **S7** | `HR-Si ×N + WGP(θ)` гибрид | N, θ | | грубо+точно, широкополосно | v1 |
| **S8** | неполяризованный / частично поляризованный вход | θ | | бюджет −3 дБ | v1 |

## 2. S1 — штатная схема прибора (база)

```
E_in(ψ) ──► WGP1(θ)  ──►  WGP2(φ₂, фикс) ──► детектор(d)
             вращается      ось ∥ d
```

Это конфигурация реальной установки владельца (подтверждено: `series1–5`, `356att`).
Соответствует Fig. 1 в Kaltenecker 2019.

**Главный результат Сессии A — теорема выравнивания (доказана аналитически, проверена
численно до 4.4e-16 и на данных):**

> если ось **пропускания** WGP2 совпадает с осью детектора `d`, то
> `d† · J_WGP2(φ₂) ≡ t⊥₂(ν) · d†` **тождественно**, при любых `E_in`, `θ`, геометрии.

Следствия для приложения:
- в идеально выставленной S1 второй WGP сводится к **скалярному множителю** `t⊥₂(ν) ≈ 0.998`
  (−0.009 дБ, не зависит от угла) ⇒ его можно не параметризовать отдельно;
- **но теорема не вакуумна**: рассогласование `φ₂ − d = 10°` даёт отклонение 6.1e-3.
  ⇒ `φ₂ − d` — реальный параметр схемы, и он должен быть в паспорте установки;
- ориентация WGP2 «провода вдоль `d`» **исключена данными**: яркое пропускание при θ=0
  было бы 0.0042 вместо 0.939. Приложение может это диагностировать само по величине
  измеренного `T(0°)`.

Референс по умолчанию: `θ = θ⁰` (Set Zero). Затухание относительное.

## 3. S2 — оба элемента подвижны

```
E_in(ψ) ──► WGP1(θ₁) ──► WGP2(θ₂) ──► детектор(d)
```

Появляется **вторая степень свободы**, и это качественно другой прибор: одно и то же
затухание достижимо на континууме пар `(θ₁, θ₂)` с `θ₁ − θ₂ = const`, но с **разным
азимутом выхода** (он задаётся `θ₂`).

Задачи решателя в S2:
- **«затухание + азимут»**: два уравнения, два неизвестных — решение единственно (с точностью
  до ветвей);
- **«затухание при максимуме сигнала на детекторе»**: `θ₂ → d`, вырождается в S1;
- **«затухание с минимальным ходом»**: минимизировать `|Δθ₁| + |Δθ₂|` при фиксированном `A*`.

Подводный камень: если `θ₂ ≠ d`, часть сигнала уходит мимо оси детектора, и **абсолютное**
затухание перестаёт быть свойством аттенюатора — оно становится свойством связки
«аттенюатор + детектор». В относительном режиме это частично сокращается, но не полностью
(проекция зависит от `θ₂`). ⇒ в S2 всегда показывать отдельно: «затухание элемента» и
«сигнал на детекторе».

## 4. S3 — «сэндвич» с фиксированными поляризаторами

```
POL(0) ──► WGP(θ) ──► POL(0) ──► детектор
 фикс      вращается   фикс
```

Схема, в которой сняты датасеты `test_grid_40_20` и на которую опираются `docs/` этого
репозитория (`transmission_sandwiched_wgp` в `model_blanco.py:173`).

Достоинства для спектроскопии:
- **выходная поляризация не меняется вообще** — ни азимута, ни эллиптичности; для
  измерений через образец это решающее преимущество (снимает проверку F8 целиком);
- отклик — чистый `cos⁴θ` в идеальном пределе; отклонение от него = прямая мера утечки
  (это и есть метод HN7 / Kaltenecker Fig. 5).

Цена: два дополнительных элемента ⇒ дополнительные вносимые потери и (для плёночных
поляризаторов на подложке) — Фабри-Перо-эхо в окне `2nd/c`.

**Замечание из исследования:** именно в этой схеме проявляется загадка `D_eff`
(`D_eff/D_phys ≈ 0.43…0.64`, пин к физическому диаметру катастрофичен). Одноэлементная
электродинамика (точный lattice-sum) даёт `≈1`. Поэтому паспорт калибровки **привязан к
схеме**: параметры, подогнанные в сэндвиче, нельзя механически переносить в S1/S2.
Это должно быть полем паспорта (`fitted_in_scheme: "S3"`) и предметом предупреждения.

## 5. S4 / S5 — аттенюатор в спектроскопическом тракте

```
S4:  источник → АТТЕНЮАТОР(θ) → образец ⟂ → анализатор → детектор
S5:  источник → образец ⟂ → АТТЕНЮАТОР(θ) → детектор
```

| | S4 (до образца) | S5 (после образца) |
|---|---|---|
| Зачем | управлять **напряжённостью поля на образце** (нелинейные эксперименты) | защитить детектор / расширить его линейный диапазон |
| Требование | поляризация на образце должна быть **постоянной** ⇒ только схемы S1/S3, не S2 | образец может деполяризовать/повернуть поляризацию ⇒ аттенюатор видит **не то**, что калибровался |
| Риск | эллиптизация в жёлтой зоне искажает возбуждение | если образец анизотропен, «затухание» зависит от образца |
| Что считает приложение | `E_на_образце(ν)` — абсолютный режим + пиковая напряжённость во времени | относительное затухание с оговоркой о входной поляризации |

Для S4 полезная надстройка: пересчёт в **пиковую напряжённость поля во временной области**
(обратное ПФ спектра после аттенюатора) — именно эта величина нужна в нелинейных
экспериментах, а не средняя мощность. Дёшево реализуется и сильно повышает ценность.

## 6. S6 — аттенюатор как элемент поляриметра

Karimi 2026 (`10.21203/rs.3.rs-8474834/v1`, PDF в `litrev/pdfs/`) показывает **in-situ
калибровку THz-TDS поляриметра при помощи заведомо «текущего» (leaky) WGP**: неидеальность
решётки не мешает, а используется как известный опорный элемент.

Для приложения это отдельный режим: не «ослабить», а «повернуть на заданный угол и выдать
предсказанную матрицу Джонса всей цепочки с доверительными интервалами». Ценно как
дифференциатор продукта, но это v2 — сперва базовые сценарии.

## 7. S7 — гибрид «HR-Si + WGP» (рекомендуется к реализации)

```
источник → [ N пластин HR-Si ] → WGP(θ) → WGP(φ₂) → детектор
             грубо, ступенями    точно, непрерывно
```

Основано на §3 Kaltenecker 2019. Пластина высокоомного кремния при нормальном падении:
`n = 3.4175` (вариация < 0.0001 до 4.5 ТГц, поглощение < 0.025 см⁻¹), полевое пропускание
прямого прохода `t = 4n/(n+1)² = 0.700`, мощностное `0.491` ⇒ **ровно −3.01 дБ на пластину**,
широкополосно и практически без дисперсии. Для `N` пластин (только прямой проход):
`t_N = 0.700^N`, `T_N = 0.5^N`.

Почему это стоит встроить:
- решает проблему **F4** (угловая разрешимость): глубокие затухания набираются пластинами,
  WGP остаётся в области малых углов, где `dA/dθ` мала;
- решает **F5** (спектральная неравномерность): кремний ослабляет ровнее, чем WGP у края
  своей полосы.

Что приложение обязано посчитать и показать:
- **временно́е окно** до первого эха: `T_win = 2nd/c` (12 пс для 525 мкм) и вытекающее
  спектральное разрешение `Δf = 1/T_win = c/2nd` (0.084 ТГц) — это прямое ограничение
  на спектроскопию;
- предупреждение, что **простой степенной закон `0.5^N` верен только для прямого прохода**;
  при учёте всех переотражений (CW/узкополосный источник) пропускание выходит на плато
  15–20 % и сильно осциллирует по спектру. Для TDS с временным окном — закон работает.

Опционально (v2) — третий вариант из статьи: **тонкая металлическая плёнка** (≈9 нм Cr на
525 мкм HR-Si) даёт 45 % по полю, широкополосно и **без эха** за счёт согласования импеданса.
Хороший «идеальный аттенюатор», но фиксированный.

---

## 8. S8 — неполяризованный или частично поляризованный вход

Если источник не полностью поляризован (степень поляризации `DOP < 1`), первый элемент
съедает в среднем **3 дБ** неполяризованной доли, и «0 дБ» относительного режима означает
уже другое. Приложение должно принимать `DOP` и азимут `ψ` (или полный вектор Стокса —
именно так устроен ввод в существующем Attenuator Studio) и явно разделять:
`потери на поляризацию` + `управляемое затухание`.

## 9. Что схема меняет в расчёте — чек-лист для реализации

| Параметр расчёта | S1 | S2 | S3 | S7 |
|---|---|---|---|---|
| число степеней свободы | 1 | 2 | 1 | 1 + дискретное `N` |
| референс относительного режима | `θ⁰` | `(θ₁⁰, θ₂⁰)` | `θ⁰` | `θ⁰`, `N₀` |
| выход поляризации фиксирован | да (`φ₂`) | нет | **да, жёстко** | да |
| нужен `φ₂ − d` в паспорте | **да** | да | нет | да |
| проверка F8 (поляризация) | смягчена | **активна** | не нужна | смягчена |
| дополнительные ограничения | — | проекция на `d` | эхо плёночных POL | эхо `T_win = 2nd/c` |
| эталонная кривая | `cos⁴Δθ` | `cos⁴(θ₁−θ₂)·cos²(θ₂−d)` | `cos⁴θ` | `0.5^N · cos⁴Δθ` |

Схема — обязательное поле каждого запроса к API (`scheme: "S1"|"S2"|…`), а не глобальная
настройка приложения: один и тот же прибор в один день работает в разных схемах.
