## 2. Режимы отсчёта — и почему относительный физически лучше

### 2.1. Три опорных уровня

| Режим | `E_ref` | `A` при опорных углах | Когда применять |
|---|---|---|---|
| **Абсолютный** | теоретический вход `S₀ = 1` | ≈ 0.5 дБ (вносимые потери `|t⊥|⁴`) | паспортизация прибора, бюджет мощности установки |
| **Относительный (set zero)** | поле при **опорных углах** `(θ₁⁰, θ₂⁰)` | **ровно 0 дБ по определению** | ежедневная работа за установкой |
| **Внешний** | загруженный измеренный референс `bg` | по данным | сверка модели с экспериментом |

### 2.2. Ключевой физический факт: в относительном режиме сокращается почти всё

Пусть амплитуды обоих каналов домножены на общий множитель потерь
`ℓ(ν) = exp(−½·(L/4.343)·ν^γ)` (он одинаков для `t⊥` и `t∥` — так устроена модель).
Тогда для относительного затухания:

```
T_rel(θ, ν) = |E_out(θ)|² / |E_out(θ⁰)|²  =  | cos²Δθ + (t∥_eff/t⊥)·sin²Δθ |²  /  |…(Δθ=0)|²
```

**Множитель `ℓ(ν)` сокращается тождественно. Сокращаются и вносимые потери `|t⊥|⁴`.**
Остаётся зависимость только от **отношения** `t∥_eff/t⊥`, то есть от коэффициента экстинкции
`ER(ν)` — и от угла.

Практические следствия, которые надо вынести в UI:

1. **Относительный режим экстраполируется существенно лучше абсолютного.** Хуже всего
   идентифицированный параметр модели — показатель рассеяния `γ` (0.2…4.2 по конфигурациям,
   Фаза 3) — из относительного расчёта **выпадает полностью**. Коридор неопределённости
   в относительном режиме за полосой калибровки в разы у́же.
2. Относительное затухание **почти не зависит от частоты** в зелёной зоне — это и есть
   `cos⁴Δθ`. Отклонение от постоянства по спектру = прямая мера неидеальности прибора.
3. **Что НЕ сокращается**: утечка `η` (она входит в `t∥_eff`, а не общим множителем) и
   `τ_leak` (каналы складываются **когерентно**, `cos²·t⊥ + sin²·t∥`, поэтому относительная
   фаза между ними влияет на модуль суммы). Именно они задают пол затухания.

⇒ **Проектное решение: относительный режим — режим по умолчанию.**

### 2.3. Set Zero: две операции, не одна

| Кнопка | Что делает | Когда |
|---|---|---|
| **Set Zero** | берёт текущее `(θ₁, θ₂)` **как есть** и объявляет 0 дБ | пользователь уже выставил рабочую точку руками |
| **Auto-Zero** | сканирует `θ₁` в окне, **ищет максимум** `U(θ₁)`, ставит туда, запоминает `θ_offset = θ_max − θ_nominal` | начало сеанса, после перестановки решётки |

Auto-Zero обязателен потому, что **механический ноль ротатора ≠ параллельность решёток**:
установочный перекос `θ_offset` — штатный параметр модели (`angle_offset`, ±10° в фитах,
типично единицы градусов).

Симметрично — **Auto-Cross**: поиск **минимума** `U(θ)`, то есть истинного скрещённого
положения. Здесь измеренный факт из Фазы 3: у образца Specac минимум оказался на **~84°,
а не на 90°**. Приложение обязано:
- искать минимум, а не подставлять 90°;
- если `|θ_min − θ_max| − 90°| > 2°`, **поднять диагностический флаг** — это либо перекос,
  либо не-Малюсова асимметрия (у Specac `U(100°)/U(80°) = 1.32`), в любом случае повод
  разобраться, а не молча считать дальше.

Запись в паспорт сессии: `zero_ref = {θ₁⁰, θ₂⁰, timestamp, method: manual|auto, U₀, θ_offset}`.
Все относительные числа в отчёте ссылаются на конкретный `zero_ref` по timestamp — иначе
через неделю невозможно понять, от чего отсчитывались дБ.

## 3. Обратная задача

### 3.1. Постановка

Дано: целевое затухание `A*` (дБ), режим отсчёта, частота `ν` **или** спектральный вес `w(ν)`
для интегрального режима, текущее положение `(θ₁, θ₂)`, конфигурация схемы, паспорт прибора.

Найти: `θ₁` (схема с одним подвижным элементом) либо пару `(θ₁, θ₂)` (два подвижных —
тогда есть дополнительная степень свободы, см. `03_OPTICAL_SCHEMES.md` §3).

### 3.2. Решение — не оптимизатор, а анализ ветвей

Для идеального предела задача решается **аналитически**:

```
cos⁴(Δθ) = 10^(−A*/10)      →      Δθ = arccos( 10^(−A*/40) )
```

Это даёт отличное начальное приближение. Дальше — одномерное уточнение по полной модели
(Брент на монотонном участке), **не** Nelder-Mead вслепую.

**Ветвей несколько.** `A(θ)` симметрична относительно опорного угла и **немонотонна**:
растёт до `θ_ext` (точка экстинкции, ~84…90°), затем падает. В диапазоне ±180° это до
**четырёх** решений. Решатель обязан вернуть **все** и ранжировать:

1. внутри монотонной ветви `[θ⁰, θ_ext]` — предпочтительно;
2. минимальный ход от текущего положения (время + износ + backlash);
3. **минимальная крутизна `dA/dθ`** в точке решения — прямо определяет достижимую точность;
4. отсутствие конфликта с механическими лимитами и кабелями.

Политика выбора — настраиваемая, дефолт: `(1) → (3) → (2)`.

### 3.3. Крутизна и достижимая точность — считать всегда

Для идеального предела `A(θ) = −40·log₁₀(cos Δθ)`:

```
dA/dΔθ  =  (40 / ln 10) · tan Δθ  ≈  0.303 · tan(Δθ)   [дБ на градус]
```

| Цель `A*` | Δθ | `dA/dθ`, дБ/град | Погрешность при шаге 1° | при 0.1° | при 0.01° |
|---|---|---|---|---|---|
| −3 дБ | 32.8° | 0.20 | 0.20 дБ | 0.02 | — |
| −10 дБ | 55.9° | 0.45 | 0.45 дБ | 0.04 | — |
| −20 дБ | 71.6° | 0.91 | 0.91 дБ | 0.09 | — |
| −30 дБ | 79.4° | 1.62 | 1.6 дБ | 0.16 | — |
| −40 дБ | 84.3° | 3.02 | **3.0 дБ** | 0.30 | 0.03 |
| −50 дБ | 86.8° | 5.4 | 5.4 дБ | 0.54 | 0.05 |
| −60 дБ | 88.2° | 9.6 | **9.6 дБ** | **0.96** | 0.10 |
| −70 дБ | 89.0° | 17.1 | 17 дБ | 1.7 | 0.17 |

Отсюда — жёсткое функциональное требование: **вместе с углом приложение всегда возвращает
`σ_A` от углового разрешения ротатора**, и если `σ_A` превышает допуск пользователя,
это **отказ**, а не успешный ответ. «Аттенюатор на −60 дБ с шагом 1°» физически бессмыслен,
и пользователь должен это увидеть до эксперимента, а не после.

К `σ_A` добавляются: люфт (backlash) ротатора, повторяемость, дрейф `θ_offset`, и
неопределённость модели `σ_db` из `01_PHYSICS_MODEL.md` §3.4 — складываются квадратично.

## 4. Границы применимости — восемь проверок

Каждый ответ решателя проходит через них. Каждая проверка — код, сообщение и **предложенное
средство**, а не просто «нельзя».

| # | Проверка | Условие отказа | Сообщение и средство |
|---|---|---|---|
| **F1** | Усиление | `A* < 0` дБ (относит.) или `A* <` вносимых потерь (абс.) | «Аттенюатор не может пропустить больше, чем при опорных углах. Минимум = 0 дБ.» |
| **F2** | **Пол затухания прибора** | `A* > A_floor(ν)` | «Максимум для этого прибора: `A_floor` дБ при θ = …°. Ограничитель — утечка параллельного канала η = …» Средство: решётка с меньшим `D/P`, либо каскад (см. `03_OPTICAL_SCHEMES.md` §7) |
| **F3** | **Динамический диапазон установки** | `A* > DR(ν) − запас` | «Физически достижимо, но **непроверяемо**: сигнал уйдёт под шум (DR = … дБ @ ν). Увеличьте усреднение или сузьте полосу.» |
| **F4** | **Угловая разрешимость** | `σ_A(шаг ротатора) > допуск` | таблица §3.3; «требуется шаг ≤ …°» |
| **F5** | **Спектральная неравномерность** | размах `A(ν)` по рабочей полосе > допуск | «Затухание неравномерно: … дБ p-p в полосе …–… ТГц.» Это главное предупреждение Kaltenecker 2019 |
| **F6** | **Зона применимости решётки** | `ν` в жёлтой/красной зоне (`01_PHYSICS_MODEL.md` §3.2) | жёлтая — предупреждение + показ эллиптичности; красная — отказ с указанием `ν_anom = c/P` |
| **F7** | **Неопределённость экстраполяции** | `σ_db(ν) > допуск` | «Частота вне полосы калибровки (…–… ТГц); неопределённость ±… дБ.» Средство: докалибровать прибор в нужной полосе |
| **F8** | **Состояние поляризации** | поворот азимута или эллиптичность на выходе > допуск | «Выходная поляризация повёрнута на …° / эллиптичность …» Средство: схема с фиксированным выходным анализатором (`03_OPTICAL_SCHEMES.md` S3) |

**Формат ответа при отказе** — не пустой результат, а ближайшее достижимое:

```json
{ "feasible": false, "failed": ["F2","F3"],
  "achievable_max_db": 34.8, "achievable_at_deg": 84.1,
  "limited_by": "leakage_floor", "dynamic_range_db": 41.2,
  "suggestions": ["добавить пластину HR-Si (+3 дБ, широкополосно)",
                  "усреднение ×4 → DR +6 дБ",
                  "сузить рабочую полосу до 0.3-1.2 ТГц"] }
```

### 4.1. Откуда берётся `A_floor`

Не из «90° = ноль», а из модели: `A_floor = −10·log₁₀( min_θ T_rel(θ, ν) )`, минимум ищется
численно (и **это не 90°**). Ограничитель — утечка `η` из паспорта. Для измеренных образцов
`η ≈ 0.012…0.036` ⇒ пол по полю ~ `η²` по мощности ⇒ порядка **−30…−38 дБ** относительно
максимума. Это реалистичная цифра, и она гораздо скромнее, чем «ER 1000:1» из каталога.

### 4.2. Откуда берётся `DR(ν)`

Тем же способом, что уже используется в этом репозитории
(`unified_optimizer/optimizer_2d.py:97-102`): шумовой пол = средняя спектральная амплитуда
фона на ВЧ-хвосте (`ν ≥ 3 ТГц`, где сигнала физически нет); `DR(ν) = (|E_bg(ν)| / шум)²`.
Требует загруженного фонового измерения — если его нет, `F3` не проверяется, и это должно
быть видно (значок «DR неизвестен»).

## 5. Сценарий S-8: развёртка уровней

Для нелинейных экспериментов нужен **ряд** уровней (напр. 0, −3, −6, −10, −20 дБ) —
типовое применение из введения Kaltenecker 2019 (исследование зависимости от пиковой
напряжённости поля).

Приложение отдаёт таблицу: уровень → угол → `σ_A` → флаги F1…F8 → ожидаемая
неравномерность по полосе. Порядок обхода оптимизируется под **монотонное движение**
ротатора (без реверсов) — это убирает люфт как источник ошибки, что для −40 дБ и глубже
критично (см. §3.3).

Полезное дополнение и хорошая практика из статьи: **грубые ступени брать пластинами HR-Si**
(ровно −3.01 дБ на пластину, широкополосно и почти без дисперсии, `t = 4n/(n+1)² = 0.700`,
`n = 3.4175`), а **тонкую подстройку — поворотом WGP**. Тогда WGP работает в области малых
углов, где `dA/dθ` мала и точность максимальна. Это снимает проблему F4 целиком.
Оговорка: пластины вносят эхо-сигналы с окном `T_win = 2nd/c` (12 пс для 525 мкм), что
ограничивает спектральное разрешение — приложение должно это посчитать и показать.

## 6. Сценарий S-11: диагностика прибора

Набор автоматических проверок «здоровья» аттенюатора по свежим измерениям:

| Метрика | Норма | О чём говорит отклонение |
|---|---|---|
| `θ_offset = θ_max − θ_nominal` | \|·\| < 2° | установочный перекос |
| `\|θ_min − θ_max\| − 90°` | \|·\| < 2° | не-Малюсова асимметрия либо перекос (у Specac было ~6°) |
| `U(θ) vs cos⁴θ`, RMS отклонения | < 1 дБ на ярких углах | деградация решётки, паразитная поляризация |
| `ER(ν) = 1/η²` | по паспорту | загрязнение/повреждение проволок |
| симметрия `U(+θ) / U(−θ)` | ≈ 1 | наклон решётки, разноплоскостность |
| `U(θ_ref+100°)/U(θ_ref+80°)` | ≈ 1 | у Specac 1.32 — мягкая не-Малюсовость, кандидат в дефекты |
| дрейф `U(θ⁰)` за сеанс | < 2 % | дрейф лазера, а не прибора — но портит все относительные числа |

## 7. Вопросы владельцу, блокирующие проектирование

1. **Оба ротатора моторизованы?** От этого зависит, есть ли обратная задача по двум углам
   (и вместе с ней — управление азимутом выхода) или только по одному.
2. **Тип детектора** — когерентный (PCA/ЭО) или мощностной (боло/пиро)? Формула затухания
   отличается множителем 2 в дБ и учётом кросс-поляризации (`01_PHYSICS_MODEL.md` §2.3).
3. **Шаг, повторяемость и люфт ротаторов** — без этих трёх чисел проверка F4 не работает,
   а без неё приложение будет уверенно врать на глубоких затуханиях.
4. **Рабочая полоса и типовой источник** — определяет дефолтный `w(ν)` и полосу калибровки.
5. **Драйверы ротаторов в v1** — реально управлять железом, или только выдавать углы?
   (Standa / Thorlabs APT / Newport / собственный протокол?)
6. **Целевая точность** — на какие допуски по `σ_A` и по неравномерности ориентироваться.
7. Каталожные `P` и `D` реальных приборов Tydex — для приоров и для сравнения с `D_eff`.
