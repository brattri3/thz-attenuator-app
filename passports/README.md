# passports/ — паспорта приборов

**Сюда кладётся паспорт вашего прибора**, полученный вместе с изделием: один JSON рядом с
программой. Файл привязан к конкретному экземпляру (серийный номер, снятые параметры) и в этом
репозитории **не хранится** — публичный репозиторий не место для данных отдельного изделия.

Обезличенный образец, на котором работают приёмочные прогоны, лежит внутри пакета:
`attenuator_app/passports/SAMPLE.json`. Числа в нём физически осмысленны, но это **не паспорт
вашего прибора** — для измерений он не годится.

⚠ `.gitignore` закрывает `passports/*.json`, чтобы реальный паспорт не уехал в открытый доступ
случайной командой `git add`. Снимать это правило не нужно: если паспорт понадобится
передать — передавайте файлом, а не коммитом.
