# THz Attenuator App

*[English version](README.md)*

Программа управления и калибровки терагерцовых аттенюаторов на проволочных поляризаторах (WGP) —
семейство **ATT-11-16-CA85**. Отвечает у прибора на один вопрос: **какое пропускание даёт пара
углов ротаторов на выбранной частоте**, и обратно — какой угол даёт нужное ослабление.

Физическая основа — модель **Бланко (1986)** в формализме матриц Джонса, дополненная проводимостью
Друде и степенным членом рассеяния. Состояние света переносится матрицей когерентности
`J = ⟨E E†⟩`: когерентный и мощностной приёмник описываются одной моделью, и фаза утечки
параллельного канала не теряется.

## Скачать

Готовая сборка под Windows x64, Python не нужен:

**[Релизы](https://github.com/brattri3/thz-attenuator-app/releases/latest)** · архив
`THz-Attenuator-<версия>-win64.zip` (около 57 МБ, около 144 МБ в распакованном виде), рядом с ним
файл контрольной суммы `.sha256`.

Распакуйте куда угодно и запустите `THz-Attenuator.exe`. Сумму стоит сверить до запуска:

```
certutil -hashfile THz-Attenuator-0.1.0-win64.zip SHA256
```

Библиотеки Qt лежат отдельными файлами рядом с программой, а не внутри неё, — чтобы их можно было
заменить своей сборкой Qt, см. [Лицензия](#лицензия).

## Паспорт прибора — прочитать до измерений

Параметры **вашего** экземпляра живут в отдельном файле-паспорте, который поставляется вместе с
изделием. В этом репозитории его нет и не будет: публичный репозиторий — не место для данных
отдельного прибора.

**Имя файла — одно правило:**

```
<обозначение>-<заводской номер>.json      например  ATT-11-16-CA85-0042.json
```

Имя файла должно совпадать с `device_id` внутри файла, символ в символ. Один прибор — один файл.
**Дату калибровки в имя не выносить:** программа перечисляет каталог по порядку и берёт первый
годный файл, поэтому два паспорта одного прибора с датами в именах дадут молча выбранную
**старую** калибровку.

**Где программа ищет паспорт**, по порядку:

1. файл, выбранный кнопкой **Passport…**;
2. рядом с программой — сначала подкаталог `passports/`, затем каталог с исполняемым файлом;
3. зашитый обезличенный образец — последним рубежом.

Что взято в итоге, написано в строке состояния. Если дело дошло до образца, там сказано
`built-in SAMPLE — not your device`: числа образца физически осмысленны, но **для измерений не
годятся**. Если имя файла разошлось с `device_id` внутри, расчёт идёт по `device_id`, и
расхождение тоже видно в строке состояния.

## Как читать числа

* **0 дБ — это максимум пропускания**, достижимый вращением решёток, а не отсчёт в нуле обеих
  шкал. При неповёрнутом источнике это одно и то же. При наклонённом максимум уезжает с нуля,
  окно называет его новое положение, и показания **несравнимы** с прогонами при другом азимуте
  источника — окно об этом предупреждает.
* Частоты за полосой калибровки считаются, но помечаются как экстраполяция, а не измерение.
* Рядом с показанием стоит цена ошибки установки в 1° по каждому ротатору и совместная оценка.

## Поведение прибора, которое не является дефектом

* Скрещенная пара **одинаковых** WGP поляризационно нейтральна: у дна на выходе воспроизводится
  состояние источника, а не ось второй решётки. Азимут держится лучше 0.4° до ~28 дБ и полностью
  теряется в последнем градусе перед скрещением.
* Максимум при вращении второй решётки у когерентного приёмника стоит **посередине** между осью
  первой решётки и осью анализатора, а не на совмещении. Наивный `argmax` даёт смещённый ноль
  калибровки.
* У мощностного приёмника вращение второй решётки даёт `cos²`, вращение первой — `cos⁴`, то есть
  вдвое по децибелам. При калибровке важно знать, какая решётка стоит в роторе.

## Обновления

Кнопка **Check for updates** читает список опубликованных релизов и отвечает одним из четырёх:
установлена последняя версия, вышла новее, релизов пока нет, проверить не удалось. Машина без
интернета у спектрометра — норма, и неудачная проверка здесь обычный ответ, а не сбой.

**Программа никогда не обновляет себя сама.** Скачивание и установку делает человек, и это
сознательное решение: приборная программа не должна меняться между двумя измерениями одной серии.

## Запуск из исходников

```
pip install -r requirements.txt
pip install PySide6-Essentials==6.11.2 pyqtgraph==0.14.0
python -m attenuator_app.cwapp
```

Qt ставится отдельной командой намеренно: полный пакет `PySide6` тянет QtWebEngine, Qt3D и
Charts — сотни мегабайт, из которых приложению не нужно ничего.

Сервисная оснастка для работы на стенде — расчёт по двум ротаторам, процедуры калибровки П0…П4 и
служебное окно на tkinter — описана в `docs/attenuator_app/`.

Используется **Qt через PySide6 на условиях LGPL-3.0**. Поэтому сборка поставляется каталогом с
