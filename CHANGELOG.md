## [0.1.0] — 2026-08-28

Первый выпуск продуктового репозитория. Поставка — **каталог**, не одиночный `.exe`
(решение владельца П-1); наружу уходит zip каталога, контрольная сумма SHA-256 считается
на архив, `LICENSES.txt` лежит рядом с `.exe` и содержит полные тексты лицензий.

### Изменено — меняет выдаваемые числа

* **Опора нормировки CW-приложения — максимум пропускания по обоим углам**, а не отсчёт при
  θ₁ = θ₂ = 0 (решение владельца П-2). ⚠ **При повёрнутом источнике (ψ ≠ 0) числа меняются**:
  при ψ = 45° опора уезжает на θ₁ +30°, θ₂ +15°. При ψ = 0 не изменилось ничего — опорная точка
  сверки с CLI (40°/0°/0.8 ТГц) прежняя: −4.77 дБ, азимут +0.023°, эллиптичность +0.630°.
  Показания несравнимы между прогонами с разным азимутом источника; окно об этом предупреждает
  и называет место опоры.

### Добавлено

* Слайдеры к полям углов ротаторов, шаг 1°, синхронно с полем.
* Поиск паспорта прибора рядом с программой (`Path(sys.executable).parent`, не `__file__`),
  с показом взятого файла в строке состояния и громким отказом негодного.
* Проверка обновлений по GitHub Releases — только по нажатию, без автообновления, на `QtNetwork`
  без новых зависимостей; окно не замирает на время запроса.
* Поставка каталогом вместо onefile (П-1): `build/gui.spec` переведён на `EXE + COLLECT`,
  Qt-DLL лежат отдельными файлами, `LICENSES.txt` кладётся рядом с `.exe`.
* Полные тексты лицензий в `LICENSES.txt` (LGPL-3.0, GPL-3.0, MIT, NumPy, Matplotlib, PSF) и
  инструкция, как получателю заменить библиотеку Qt своей сборкой — то самое право, ради
  которого поставка перестала быть onefile.

### Исправлено

* Стрелки `QDoubleSpinBox` рисует нативный стиль: кнопка «вверх» снова различима. Правило
  таблицы стилей переводило виджет в разбор QSS целиком, и стрелка срезалась до чёрточки —
  щелчок при этом исправно шагал значение, поэтому числовые проверки дефекта не видели.

### Приёмка выпуска

Прогнана ORCH самостоятельно на объединённом состоянии: `cwapp` **27/27**, база 13/13,
сервисное (модель / пределы / калибровка 8/8 / приложение 7/7), CW-кривая 5/5, сверка ядра —
9 файлов без расхождений, дымовой прогон окна на живой платформе зелёный (15 снимков).

⚠ Дымовой прогон на платформе по умолчанию (`offscreen`) даёт 8 ложных отказов по стрелкам
спинбокса: нативный стиль там их не рисует. Запускать с `QT_QPA_PLATFORM=windows`; починка
самой проверки — в 0.2.0.

### Состав сборки

Python 3.14.4, PySide6-Essentials 6.11.2, shiboken6 6.11.2, pyqtgraph 0.14.0, NumPy 2.5.0.
Matplotlib и SciPy исключены из `.exe` явно. Модули Qt: `QtCore`, `QtGui`, `QtWidgets`,
`QtNetwork`, `QtOpenGL`, `QtOpenGLWidgets`, `QtSvg`, `QtTest` — всё из Essentials под LGPL-3.0,
QtWebEngine и Charts в сборке нет. Каталог 144 МБ.

### Что приехало

* CW-приложение на PySide6 (`attenuator_app/cwapp/`) — расчётный слой, окно, тема, состояние.
* Сервисный контур на два ротатора: модель на матрице когерентности, пределы прибора, пять
  процедур калибровки оператором, обратная задача по паре «ослабление + азимут».
* Приложение v0.3 на tkinter и CW-кривая — до конца приёмки у прибора.
* Документация оператора и разработчика (`docs/attenuator_app/`).

### Что осталось в исследовательском репозитории

Генераторы паспортов и калибровок из измерений, приёмка на измеренных данных (69/69), просмотр
измеренных кривых. Это инструменты производства паспорта, а не части изделия.

  70 проверок и 15 снимков.

### Решения владельца

* **П-1, LGPL и onefile:** поставка **не onefile**. Собираем папкой (`COLLECT`), Qt-DLL лежат
  отдельными файлами рядом с `.exe` — получатель может заменить Qt своей сборкой, чего и требует
  LGPL. Наружу уходит zip-архив каталога, SHA-256 считается на архив. Разбор — `LICENSES.txt`.
* **П-2, нормировка при повёрнутом источнике:** опора — **максимум кривой**, а не отсчёт при
  θ₁ = θ₂ = 0. Меняет выдаваемые числа при ψ ≠ 0 и требует пересмотра проверки M2.
* **П-3, тег `v0.1.0`:** отложен до правки 3 — релиз до неё устарел бы по числам в тот же день.
