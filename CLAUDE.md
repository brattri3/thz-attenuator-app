# Claude Code

## Именование сессии

1. Назови сессию: `claude -n app` или `claude -n orch` (или `/rename`).
2. Один раз проверь `claude agents --json`: если сессия с твоим именем уже `busy` в этом `cwd` —
   не стартуй, скажи владельцу. `claude agents` видит только сессии Claude Code на этой машине —
   это подсказка от случайного двойного старта, не источник истины про «кто сейчас работает»
   (им остаётся git, см. `AGENTS.md`).

## Подагенты, teammates и эта оснастка

Claude Code умеет распараллеливать работу внутри одной сессии (подагенты) и между несколькими
сессиями, которые сама же и порождает (agent teams, экспериментально, по умолчанию выключено).
Оба механизма полезны и ни один не заменяет журналы: их состояние живёт в `~/.claude/`, скопом на
сессию, и стирается по её завершении. `coordination/*.md` живёт в этом git-репозитории и переживёт
любую сессию. Порождай подагентов для параллельной разведки сколько нужно — но решение, задание
другой роли или смену состояния записывай в `HANDOFFS.md`, `QUESTIONS.md` или `ACTIVITY.md` до
конца сессии.

## Path-правила

Команды, форматы или контекст, нужные только на конкретных путях, — в `.claude/rules/*.md` с
`paths:` во фронтматтере, а не в этом всегда загруженном файле. Пока не заведено ни одного —
`docs/attenuator_app/` читается по явной ссылке из `AGENTS.md`, отдельного правила не требует.

## Автоматические проверки

| Хук | Событие | Эффект |
|---|---|---|
| `check-context-budget.py` | `SessionStart` | предупреждает при превышении бюджета файла роли/`CLAUDE.md`/`AGENTS.md`; **никогда не блокирует** |

Хук идёт чистым апстримом (`c2ef7d2`), локальных правок нет; бюджеты — `.claude/hooks/budget.json`
(2400 Б для файлов ролей — наша более жёсткая калибровка, 200 строк для `CLAUDE.md`/`AGENTS.md` —
апстримный порог).

Апстрим предлагает ещё два хука — владения путями (`check-path-ownership.py`) и трейлеров коммита
(`check-commit-trailers.py`); сознательно не подключены, решение владельца впереди (`QUESTIONS.md`
П-6).
