# CLAUDE.md — THz Attenuator App

Приложение для управления и калибровки терагерцовых аттенюаторов на проволочных поляризаторах
(WGP, семейство **ATT-11-16-CA85**): считает угол поворота по нужному ослаблению и обратно, ведёт
калибровку на стенде, отмечает зашкал и границу чувствительности приёмника.

Язык документации, комментариев и коммитов — **русский**. Интерфейс приложения — английский.

## Что это за репозиторий

**Продуктовый.** Отсюда идёт поддержка и обновление приложения. Заведён 2026-08-27 переносом
продуктового контура из исследовательского `THz-Unified-Optimizer` (точка отделения и состав —
`CHANGELOG.md`). История не переносилась намеренно.

**Поток вещества односторонний:** физика зреет в исследовательском репозитории, сюда приезжает
застывший результат. Генераторы паспортов и калибровок из измерений, приёмка на измеренных данных
и просмотр измеренных кривых остались там — это станок, а не изделие. Обратного переноса не бывает.

## Гардрейлы — нарушение необратимо

- **Репозиторий публичный.** Данные конкретного экземпляра прибора сюда не попадают: ни серийный
  номер, ни снятая с него калибровка, ни измеренные спектры. `passports/*.json` закрыт
  `.gitignore` — правило не снимать. Приёмка идёт на обезличенном `SAMPLE`.
- **`git push` — только с прямого разрешения владельца.** Форс, `rm -rf`, переписывание истории —
  никогда.
- **Физику не менять молча.** Модель перенесена из исследовательского репозитория и сверена там;
  расхождение чисел приёмки означает дефект, а не улучшение. Нужна правка физики — сначала вопрос
  владельцу.
- **Правку интерфейса проверять живым запуском, а не импортом.** Оба урока получены дорого:
  мок-импорт пропускает разрыв метода, а числовые проверки не видят пропавший индикатор
  радиокнопки, запятую вместо точки в локали и срезанную рамкой подпись — эти четыре дефекта нашёл
  снимок живого окна, когда все прогоны были зелёными.
- Коммит: префикс роли `[<ID>]` + трейлеры последним абзацем без пустой строки внутри
  (`Session: <ID>`, `Reason: <в одну строку>`). Коммитить только свои пути, `git add -A` — нет.

## Команды

```
pip install -r requirements.txt
pip install PySide6-Essentials==6.11.2 pyqtgraph==0.14.0

python -m attenuator_app.cwapp                       # основное CW-приложение (PySide6)
python -m attenuator_app.tools.service_gui           # сервисное окно наладчика (tkinter)
python -m attenuator_app.tools.service_calc --help   # сервисный расчёт, два ротатора
python -m attenuator_app.tools.service_calibrate --plan   # процедуры калибровки П0…П4
```

Приёмка целиком — четыре прогона, ожидаемые числа:

```
python -m attenuator_app.cwapp.selftest           # 12/12
python -m attenuator_app.selftest                 # 13/13
python -m attenuator_app.tools.service_selftest   # модель OK, пределы OK, калибровка 8/8, приложение 7/7
python -m attenuator_app.cw_curve --selftest      # 5/5
```

Опорная точка сверки интерфейса против CLI —
`service_calc --from-angle 40 --theta2 0 --freq 0.8` даёт `−4.77 дБ`, азимут `+0.023°`,
эллиптичность `+0.630°`. Расхождение здесь — дефект, а не округление.

Проверка `A7` в `service_selftest` **пропускается штатно**: она сверяет модель с независимой
реализацией из исследовательского репозитория, которого здесь нет, и говорит об этом явно.

## Физика: что не переоткрывать

- Скрещенная пара **одинаковых** WGP поляризационно нейтральна: у дна на выходе воспроизводится
  состояние источника, а не ось второй решётки. Азимут держится лучше 0.4° до ~28 дБ и полностью
  теряется в последнем градусе перед скрещением. **Это не дефект.**
- Максимум при вращении второй решётки у когерентного приёмника стоит **посередине** между осью
  первой решётки и осью анализатора, а не на совмещении. Наивный `argmax` даёт смещённый ноль.
- У мощностного приёмника вращение второй решётки даёт `cos²`, вращение первой — `cos⁴`, вдвое по
  децибелам. При калибровке важно знать, какая решётка в роторе.

Подробности и числа — `docs/attenuator_app/`.

## Координация сессий

Скилл `.claude/skills/multi-agent-coordination` **подключён, но не развёрнут**: каталога
`coordination/` здесь пока нет. Если над репозиторием будет работать больше одной сессии —
разверни скилл (он спросит про роли и зоны) и добавь сюда раздел про роли. Пока сессия одна,
координация не нужна — не заводи её «на всякий случай».

⚠ В хуке бюджета из скилла есть **локальная правка**: `tr -d '\r'` перед подсчётом байтов. Без неё
на Windows CRLF добавляет байт на строку, все файлы ролей выглядят нарушителями лимита, и
предупреждение перестаёт читаться. Апстрим (`e02be1e`) правку ещё не знает — при обновлении скилла
её надо вернуть или отправить в апстрим.
