# Кроссплатформенный мост: Работа любых агентов с координационным скаффолдом

Этот документ описывает, как разные инструменты (Google Antigravity, Claude Code, Cursor, Aider) могут бесшовно взаимодействовать в одном проекте, используя этот Git-ориентированный скаффолд.

## 1. Агностичность к моделям и платформам

Ключевой принцип данного подхода: **скаффолду неважно, какая нейросеть или платформа исполняет роль**. 
- Нет жестко зашитой привязки "Antigravity = Архитектор, Claude Code = Разработчик".
- Специфика определяется исключительно **содержимым командных файлов (md файлов в `coordination/roles/`)**, которые читаются при первой инициализации свежей сессии.
- Любая платформа, способная прочитать стартовый `.md` файл и сделать коммит в Git, становится полноправным участником.

## 2. Общий жизненный цикл сессии (Для любой платформы)

1. **Изоляция:** Каждая роль (независимо от того, запускается она в Antigravity, Claude Code или локально человеком) должна работать в собственной ветке или `git worktree` (см. `coordination/tools/worktree_launcher.py`).
2. **Инициализация:** При старте агент должен получить в системный или стартовый промпт инструкцию прочитать свой файл роли: `coordination/roles/<ROLE_ID>.md`. Этот файл задает контекст, задачи и границы зоны ответственности.
3. **Хуки и Бюджет:** Хук проверки бюджета (`check-context-budget.py`) срабатывает одинаково. Он носит **предупреждающий характер** (мягкий лимит). Агентам строго **запрещается** агрессивно сжимать или удалять командные файлы без явного согласия человека, управляющего проектом. Управление контекстом — привилегия человека.
4. **Коммуникация:** Общение между ролями (и между LLM разных платформ) идет асинхронно через `QUESTIONS.md` (блокирующие вопросы) и `HANDOFFS.md` (делегирование задач).
5. **Фиксация результатов:** Все коммиты должны содержать префикс и трейлер (например, `Role: frontend`), чтобы инструмент `kpi_git.py` мог корректно посчитать вклад каждой роли, независимо от того, какая платформа сгенерировала коммит.
